# 🌦️ Weather Dashboard

A simple and clean **Weather Dashboard** built using **HTML, CSS, and JavaScript**.
This project fetches real-time weather data using the **OpenWeatherMap API** and displays it based on the city entered by the user.

---

## 🔗 Live Demo

*(After enabling GitHub Pages)*

```
https://anand16-info.github.io/Weather-Report/
```

---

## 📌 Features

* Search weather by **city name**
* Displays:

  * City name
  * Current temperature
  * Weather condition (Clear, Cloudy, Rain, etc.)
* Dynamic UI update using JavaScript
* Simple and beginner-friendly design

---

## 🛠️ Tech Stack

* **HTML** – Page structure
* **CSS** – Styling
* **JavaScript** – API handling & DOM manipulation
* **OpenWeatherMap API** – Weather data

## ⚙️ How the Project Works

1. User enters a city name in the input box
2. On clicking **Search**, a request is sent to OpenWeatherMap API
3. Weather data is fetched using JavaScript `fetch()`
4. City name, temperature, and weather condition are displayed on the screen

---

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/anand16-info/Weather-Report.git
```

2. Open the project folder:

```bash
cd Weather-Report
```

3. Open `index.html` in your browser
   *(Recommended: Use VS Code Live Server)*

---

## 🔑 API Setup

1. Visit: [https://openweathermap.org](https://openweathermap.org)
2. Create an account and generate an API key
3. Open `script.js` and replace:

```js
const weatherApiKey = "YOUR_API_KEY";
```
